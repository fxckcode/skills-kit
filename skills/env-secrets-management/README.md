# env-secrets-management

Manage .env files, API keys, passwords, and sensitive configuration values — including workarounds for tool output censorship.

## Install

```bash
npx skills add fxckcode/skills-kit/skills/env-secrets-management
```

Or copy:

```bash
cp -R env-secrets-management "$HOME/.agents/skills/env-secrets-management"
```

## Trigger Phrases

- "manage secrets"
- "create .env"
- "API key setup"
- "password authentication failed"
- "secret censoring"
- "prisma db push auth"

## Compatibility

- Linux, macOS
- Works with Docker, Node, Python, Go
- Agnostic to agent platform
