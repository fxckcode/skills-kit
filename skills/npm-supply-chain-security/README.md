# npm-supply-chain-security

Three-layer npm supply chain security: consumer basics, PNPM hardening, and publisher best practices (OIDC, Provenance, 2FA).

## Install

```bash
npx skills add fxckcode/skills-kit/skills/npm-supply-chain-security
```

Or copy to your agent's skills directory:

```bash
cp -R npm-supply-chain-security "$HOME/.agents/skills/npm-supply-chain-security"
```

## Trigger Phrases

- "secure my npm project"
- "supply chain security"
- "npm audit hardening"
- "postinstall risks"
- "pnpm security"

## Compatibility

- Works with npm, pnpm, and yarn
- Linux, macOS, Windows
- Compatible with Claude Code, OpenCode, Gemini CLI, Codex
