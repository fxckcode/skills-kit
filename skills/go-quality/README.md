# go-quality

Go project quality standards — linting, race detection, CI setup, error wrapping, context propagation, and test isolation.

## Install

```bash
npx skills add fxckcode/skills-kit/skills/go-quality
```

Or copy:

```bash
cp -R go-quality "$HOME/.agents/skills/go-quality"
```

## Trigger Phrases

- "set up a Go project"
- "review Go code"
- "Go quality standards"
- "go lint, vet, race"
- "Go CI setup"

## Compatibility

- Requires Go 1.22+
- Linux, macOS
- GitHub Actions for CI
