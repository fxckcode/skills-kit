# verification-loop

Structured 7-phase verification system for code changes: Build → Type → Lint → Test → Spec → Security → Smoke.

## Install

```bash
npx skills add fxckcode/skills-kit/skills/verification-loop
```

Or copy:

```bash
cp -R verification-loop "$HOME/.agents/skills/verification-loop"
```

## Trigger Phrases

- "verify this"
- "smoke test"
- "review this change"
- "audit this project"
- "run verification"

## Compatibility

Works with any stack: Node, Python, Go, Rust, or anything with a build/test pipeline.
