# codebase-audit

Systematic codebase audit — gap analysis against specs, architecture review, code quality assessment, and migration readiness checks.

## Install

```bash
npx skills add fxckcode/skills-kit/skills/codebase-audit
```

Or copy:

```bash
cp -R codebase-audit "$HOME/.agents/skills/codebase-audit"
```

## Trigger Phrases

- "review this codebase"
- "audit this project"
- "how does this compare to the spec"
- "gap analysis"
- "review this PRD against the code"

## Compatibility

Stack-agnostic — works with any language or framework.
